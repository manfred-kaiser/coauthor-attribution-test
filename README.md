# Co-Author Attribution Test

Test repo to check whether GitHub links a Co-authored-by trailer to a real account/profile even when the listed co-author email is not that account's primary/verified email.

Third test: noreply@ssh-mitm.at as PRIMARY author, no co-author trailer at all (replicating the real-world pattern from the investigated wiki repos, where the Claude identity was the commit author, not a trailer).
